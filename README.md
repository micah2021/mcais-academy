# 🛡️ ShieldMark Africa

**Africa's first consent-first digital content protection platform.**

Protect your images before they spread online. Built for Nigeria, designed for Africa.

## Features
- 🔒 Image fingerprinting (perceptual hash — no original stored)
- 🔍 Automated scanning for matches online
- 🚨 Instant alerts when your image is found
- 📋 DMCA takedown letter generation
- 💳 Subscription plans via Flutterwave

## Run locally
```bash
pip install -r requirements.txt
streamlit run image_protector.py
```
